# Learning Journey

My early projects from 2023, collected in one place. They show where I started with programming and data analysis. Each folder keeps its original commit history.

For my current work in data engineering and machine learning, see my pinned repositories, e.g. [Virtual-Flow-Meter](https://github.com/AhmadSidaoui/Virtual-Flow-Meter) and [NexusFlow](https://github.com/AhmadSidaoui/NexusFlow).

## 01 · Programming fundamentals

| Project | What it does | Tech |

| [Rock-Paper-Scissors](01-programming-fundamentals/Rock-Paper-Scissors) | Classic browser game against the computer | JavaScript, HTML, CSS |
| [TODO_LIST](01-programming-fundamentals/TODO_LIST) | Console app to add, remove and view to-dos | C# |
